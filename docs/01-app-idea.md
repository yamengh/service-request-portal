# Service Request Portal

## App Idea

The Service Request Portal is a simple web application that provides users with an intuitive interface to submit service or support requests and view the status of their requests.

The goal of the Week 1 prototype is to create a professional and responsive frontend interface that demonstrates the core user experience of a service-request system.

The application will allow users to:
- View a dashboard
- Create a new service request
- View their submitted requests
- Open a request to see its details

The Week 1 version will use mock data and will not include a backend, database, authentication, real API integration, AI services, or workflow automation.

## Target User

The primary user is an employee or organization member who needs to submit and track a service or support request.

## Week 1 Goal

The goal is not to build a complete enterprise system. The goal is to learn and demonstrate an AI-assisted software development workflow while producing a clean, usable frontend prototype that can later be extended in subsequent internship weeks.
